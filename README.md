## Algumas Questões Importantes ao Desenvolver seu Trabalho !!! 👋

🌱 Identifique se há algum requisito importante para a construção do sistema que não está sendo devidamente esclarecido no contexto apresentado ou que esteja criando algum conflito com outro já informado. Nesse caso, o grupo deve encaminhar mensagem ao professor (✨que é o demandante do projeto✨) através do **comentário geral do classroom** (em casos especiais utilize o comentario particular), a fim de sanar as dúvidas sobre o assunto.

🔭 Utilize uma ferramenta de apoio ao método Scrum + Kanban, como (Trello, Jira, Moday, Confluence, etc) para distribuição das tarefas. ✨É responsabilidade do Scrum Master✨ a devida distribuição e controle das atividades do grupo, mas essa ✨responsabilidade deve ser compartilhada✨.
